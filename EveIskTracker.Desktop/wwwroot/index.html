Game Overlay

In-Game-HUD über dem EVE-Client · DPS live
IN-GAME OVERLAY
Legt sich wie das Discord-Overlay über den EVE-Client: immer im Vordergrund, durchklickbar, stiehlt dem Spiel nie den Fokus. Hotkey Strg + Umschalt + O blendet es jederzeit ein und aus — auch mitten im Spiel.
Wichtig: EVE muss im Fenstermodus oder randlosen Vollbild laufen; im exklusiven Vollbild ist kein Overlay sichtbar.
Im Verschieben-Modus verwandelt sich das Overlay in eine Greif-Karte — mit der Maus an die Wunschposition ziehen und „OK" drücken.
Detailliert Kompakt
Detailliert = Graph + Summen · Kompakt = schmale Zahlenzeile
95 %
DPS-QUELLE · COMBAT-LOG
Der Schadensgraph liest EVEs Game-Logs (Documents\EVE\logs\Gamelogs) live mit — rein lokal, ohne Eingriff ins Spiel. Er folgt automatisch dem zuletzt aktiven Client: wechselst du den Charakter, springt die Anzeige binnen Sekunden aufs neue Log um.
